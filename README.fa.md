## وضعیت پروژه

این مخزن در مرحلهٔ راه‌اندازی است. پیاده‌سازی SDK هنوز شروع نشده و بسته‌ای هم در Packagist منتشر نشده است؛ بنابراین در حال حاضر نسخهٔ قابل نصب یا API پایدار PHP وجود ندارد.

## دربارهٔ سفیر

سفیر سرویس پیام‌رسانی کسب‌وکار بله است. وب‌سرویس REST آن امکان ارسال پیام به شمارهٔ تلفن را فراهم می‌کند و از متن، رسانه، پیام رمزدار، رمز یک‌بارمصرف، دکمه‌های شیشه‌ای و قالب‌های تأییدشده پشتیبانی می‌کند. فایل ابتدا بارگذاری می‌شود و سپس شناسهٔ `file_id` آن در پیام استفاده می‌شود.

وب‌سرویس سفیر از هدر `api-access-key` سازمان، `bot_id` و `phone_number` استفاده می‌کند. این سرویس با وب‌سرویس بازوهای بله و مدل احراز هویت آن‌ها متفاوت است؛ این بسته برای توکن بازو، شناسهٔ گفتگو، دریافت به‌روزرسانی‌ها یا وب‌هوک‌ها نیست.

## قابلیت‌های برنامه‌ریزی‌شده

- ارسال پیام متنی و چندرسانه‌ای، از جمله پیام رمزدار و OTP.
- ساخت دکمه‌های شیشه‌ای برای پیوند، وب‌اپ و کپی متن.
- ارسال قالب‌های تأییدشده با فیلدهای متنی.
- بارگذاری فایل و استفاده از `file_id` دریافتی در پیام.
- پشتیبانی از `request_id` برای جلوگیری از ارسال تکراری.
- پاسخ‌های تایپ‌شده، جزئیات خطا و پشتیبانی اختیاری لاراول با Facade و تنظیمات.

این قابلیت‌ها بر اساس مستندات رسمی برنامه‌ریزی شده‌اند و هنوز پیاده‌سازی نشده‌اند.
